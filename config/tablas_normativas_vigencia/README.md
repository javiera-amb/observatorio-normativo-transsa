# Certificados de vigencia de Tablas Normativas

Esta carpeta contiene únicamente certificados generados por el motor V5 cuando una comuna acredita la misma `version_normativa_id` en seguimiento normativo, tabla y SIG.

Regla **fail-closed**: la ausencia de certificado, una versión distinta, un acto posterior faltante, una auditoría vencida o un control obligatorio no aprobado bloquean la publicación de la comuna.

Los archivos JSON son generados automáticamente. No deben crearse a mano para saltar controles.
