ACTUALIZACIÓN INCREMENTAL — VIGENCIA CARTOGRÁFICA
================================================

Esta carpeta está diseñada para copiarse SOBRE el repositorio actual.
No elimina ni reemplaza las bases existentes:
- data/reportes.js
- data/ipt_reportes.js
- data/historicos.js

PASOS
1. Abre el repositorio local con GitHub Desktop → Show in Explorer.
2. Copia todo el contenido de esta carpeta y pégalo en la raíz.
3. Acepta reemplazar index.html, app.js, styles.css, requirements.txt,
   validar_sitio.py, README.md, CONFIGURACION_AUTOMATICA.md y
   actualizar-ipt.yml.
4. En GitHub Desktop:
   Summary: Agregar vigencia cartográfica de IPT
   Commit to main
   Push origin
5. Espera el despliegue de Cloudflare.
6. En GitHub ejecuta:
   Actions → Actualizar vigencia cartográfica → Run workflow.

PRIMER RESULTADO
Los actos IPT existentes sin un shape registrado aparecerán como
"Sin cartografía". Para comparar un shape real, completa:
config/cartografia_ipt.json

Usa config/cartografia_ipt_ejemplo.json como referencia.
